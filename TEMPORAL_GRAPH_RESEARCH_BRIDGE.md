# Fibonacci–Lucas tower and temporal graph research

Canonical E47-style temporal graph link-prediction benchmark documentation, code and reported results: [E47-Kartekeya / temporal-graph-learning](https://github.com/nicholaskouns-create/E47-Kartekeya/tree/main/temporal-graph-learning).

This repository remains the canonical home for the Fibonacci–Lucas tower, its exact combinatorial identities and validators. The rank-k random projector in the benchmark is only **occupancy-matched** to the base E47 fraction 47/125. It is not the exact Casimir spectral selector and does not test tower-index scaling.

A meaningful tower experiment would explicitly construct each selector, define an equivariant map to graph embeddings, and compare its performance against matched-rank random and learned projectors with identical evaluation conditions.
